# NIRU — DARK RITUALS II

**32 dark ambient tones for the Roland GAIA 2**

Created by **Nicklas Rudolfsson** · 2026

A companion collection of ritual drones, spectral choirs, shadowy bells,
industrial textures and sub-bass. Each of the 32 tones has its own name and
oscillator program. The download includes a full bank and individual files.

This is an **early version** and may be updated. Created for my own music and
shared freely for use in yours; see the notice below regarding Roland-owned material.

> **Hardware testing pending:** the SVZ structure and checksums have been
> checked in software, but the tones have not yet been imported or auditioned
> on a physical GAIA 2. Musical descriptions are design intentions.

## Install

1. Back up any user tones you wish to keep: imports overwrite selected slots.
2. Copy `NIRU_DARK_RITUALS_II.svz` to `ROLAND/SOUND` on a GAIA 2-formatted
   or compatible FAT32 USB drive.
3. Connect the drive to the GAIA 2 and choose **MENU → File → Import**.
4. Select the bank, choose the tones and destination slots, and confirm.

The `patches/` directory contains the same tones as individual `.svz` files.
